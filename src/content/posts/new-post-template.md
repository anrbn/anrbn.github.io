Start writing here. Delete these instructions when the post is ready.

Use ordinary Markdown for paragraphs, **emphasis**, lists, and links.

Inline equations use dollar signs: $e^{i\pi} + 1 = 0$.

Display equations use two dollar signs:

$$
\int_0^\infty e^{-x^2}dx = \frac{\sqrt{\pi}}{2}
$$

Fenced code blocks receive syntax highlighting automatically:

```typescript
export function greet(name: string) {
  return `Hello, ${name}`;
}
```

A good note is not a perfect record. It is a small surface that gives an idea somewhere to land, and enough context that you can recognize it when you return.

Most systems begin with the promise that nothing will be lost. Soon they contain everything: quotations without questions, links without reasons, and careful categories that describe where an idea came from but not why it mattered.

The useful question is simpler: what must this note preserve so that a future version of me can continue the thought?
